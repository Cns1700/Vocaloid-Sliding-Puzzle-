# ボーカロイド スライディングパズル

*[English version is here](README.md)*

初音ミク（複数のモジュール）と **VFlower V3** をフィーチャーした、無料・非営利のファンメイド・スライディングパズルギャラリーです。キャラクターを選んでイラストを選び、タイルを正しい位置にスライドさせて完成させましょう。

ブラウザだけで遊べます。インストール不要・アカウント不要・広告なし。

**ライブデモ:** [cns1700.github.io/Vocaloid-Sliding-Puzzle-](https://cns1700.github.io/Vocaloid-Sliding-Puzzle-/)

## 特徴

- **5つのキャラクターテーマ** — 初音ミク（オリジナル）、Supreme、Honey Whip、25時、VFlower V3。それぞれ独自のアクセントカラーとイラストセットを持ちます。
- **グリッド変更可能** — 難易度を3×3から8×8まで変更できます（行と列は独立）。
- **タイマーと手数カウンター**、一時停止対応。
- **ヒント機能** — 正しい番号を4秒間表示（回数制限あり）。
- **オートソルブ** — マンハッタン距離ヒューリスティックを使った本物のA*探索で解を見つけ、アニメーションで再生します。非常に大きなグリッドではブラウザが固まらないよう、記録されたシャッフル経路にフォールバックすることがあります。
- **結果証明書** — 手動クリアかオートソルブかを明示した画像をダウンロード／コピーできます。
- キーボード操作対応（タイルは本物のボタン、Enter / Spaceでスライド）。

## 遊び方

1. **ギャラリー**から好きなサムネイルをクリックして、そのイラストのパズルを開きます。
2. **空白の隣にあるタイル**をクリック（またはキーボードで選択）してスライドさせます。
3. すべてのタイルを正しい位置に並べ替えてイラストを完成させます。
4. コントロールバーの機能：
   - **グリッド設定** — 行・列を3〜8に変更
   - **一時停止** — タイマーを止め、ボードを隠す
   - **ヒント** — 番号を短時間表示
   - **オートソルブ** — ソルバーにボードを解いてもらう
5. 完成すると、タイム・手数・共有可能な証明書画像付きの勝利パネルが表示されます。

## ローカルで動かす

ビルド手順や依存関係はありません。

- `index.html` をブラウザで直接開く、または
- 静的ファイルサーバーでフォルダを配信する（例: `python -m http.server` → `http://localhost:8000`）
